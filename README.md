# Gym Tracker (PWA)

1. Создай репозиторий на GitHub, загрузи в корень ВСЕ файлы и папку icons.
2. Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.
3. Открой https://ТВОЙ_НИК.github.io/ИМЯ_РЕПО/ в Safari на iPhone.
4. Поделиться -> На экран Домой.
5. Старые данные: Ещё -> Импорт данных -> выбери gym-tracker-backup-2026-11-09.json
